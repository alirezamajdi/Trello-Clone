# Trello Clone

A Trello-like task management application built with modern web technologies.  

---


## Tech Stack

- **Framework:** Next.js (App Router)  
- **Styling:** SCSS Modules  
- **State Management:** Zustand  
- **Drag & Drop:** @dnd-kit  

---

## Getting Started

### Prerequisites

- Node.js v18+  
- npm or yarn  

### Installation

```bash
git clone <your-repo-url>
cd trello-clone
npm install
# or
yarn install

# Running Locally
npm run dev

# Building for Production
npm run build
